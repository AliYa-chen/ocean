# 海洋场景与功能实验室

运行 `pnpm dev`，默认进入海洋场景。顶部可以切换“海洋场景 / 功能实验室”。
`/?scene=ocean` 和 `/?scene=lab` 可直接访问。场景模块按需加载；切换会释放
渲染器、帧循环、监听器、纹理和后处理资源，海洋参数在当前页面内保留。

## 操作

| 操作 | 方法 |
| --- | --- |
| 环绕 / 漫游 / 航行 | 左上按钮，或数字键 1 / 2 / 3 |
| 环绕视角 | 左键旋转、右键平移、滚轮缩放 |
| 漫游 | WASD / 方向键移动，Q 下潜、E 上浮，Shift 加速，左键转向 |
| 航行 | W/S 前进后退，A/D 转向；船体随海浪浮动 |
| 水下观察 | “探索水下世界”按钮 |
| 暂停全部 | 右侧开关 / 空格，冻结海水、云层与太阳时间 |
| 参数面板 | 右下按钮 / H |
| 重置、截图、全屏 | 参数面板底部 |

输入框、下拉框和可编辑内容拥有焦点时不会抢占键盘操作。按钮上的空格保留点击行为。
航行有海岛与活动范围限制。

## 天气控制

右侧参数分为 `local date`、`clouds`、`atmosphere`、`ocean`，可分别折叠。

| 分组 / 控件 | 行为 |
| --- | --- |
| local date / dayOfYear | 1–365 年内日期，可拖动或输入；第 1 天为 1 月 1 日 |
| local date / timeOfDay | 0–24 小时，可拖动或输入；24:00 自动进入下一天 |
| local date / animate、stop | 播放 / 停止太阳时间，停止时保留当前日期和时刻 |
| local date / speed | -0.5 至 0.5，负数倒放，0 冻结；默认 0.05，每真实秒推进 3 小时 |
| clouds / animate | 独立启停体积云运动，不影响海浪或太阳动画 |
| clouds / speed、coverage | 云速 0–5 倍、云覆盖 0–100% |
| atmosphere / exposure、haze | 调节天空与反射的 HDR 曝光，以及官方云层大气薄雾 |
| ocean | 原有海况、渲染质量、像素倍率和浮力 / 尾流探针 |

日期采用固定 2026 非闰年，复现参考的 1–365 范围；坐标采用 Tokyo 示例的
139.8146°E / 35.7455°N。时间为当地平均太阳时（经度 / 15），不随电脑时区改变。
使用官方 `getSunDirectionECEF` / `getMoonDirectionECEF` 计算真实太阳和月亮方向，
再转到海洋的 X 东 / Y 上 / Z 南坐标；日期会改变太阳季节轨迹。
官方大气透射 LUT 决定直射光颜色，太阳方向同步影响天空、云层散射、船体光照 / 阴影
以及海面太阳高光。月亮使用独立星历，不简单设为太阳的反方向。

太阳动画沿用参考的 speed 含义（以 60 FPS 为基准），按帧间隔积分，支持跨午夜、
年末循环和倒放；切到后台暂停推进。编辑日期、时间或选择预设会停止太阳播放。
云动画默认开启，使用参考的 `localWeatherVelocity = (0.001, 0)` 对应偏移速度，
由单一海洋帧循环驱动；云、太阳各有独立时钟。全局暂停冻结全部时钟，仍可手动调节天气。
重置恢复第 170 天 15:00，云动画开启、太阳播放关闭。切换到功能实验室再返回时保留有效日期。

## 复刻范围

- 参考站同款本地帆船、岛屿、浮标、礁石、海草和鱼群模型。
- 三层 JONSWAP 波谱（256 / 32 / 4 米），GPU 二维逆 FFT 同时求出波高与水平位移。
  波浪导数用于法线和 Jacobian 压缩判断；白沫由抬高且受压缩的浪峰产生，
  在双缓冲中随流动漂移、衰减。起沫强度与表面覆盖率分开计算，
  浪尖只显示细丝状气泡壁，残留白沫逐渐变淡，不将高浪峰填成整片白色。
  透明覆盖贴图先提取再生成 mipmap，保留近处孔隙、远处的低覆盖率；
  细节层只调制丝状纹理，不往空隙叠加灰白底色。
- 波浪法线驱动的天空反射、带深度遮罩的船体平面反射、屏幕深度折射、
  水深吸收、菲涅耳反射、GGX 太阳高光、波峰透光、岸边泡沫与航行尾流。
- 船体接水泡沫使用真实场景深度交界，不再围绕船体绘制椭圆泡沫圈。
  船侧暖色补光配合日光高光；船影以视空间法线扰动，随浪面破碎。
- CPU 从同一波谱选取主导波模态，为船体、浮标和探针提供平滑浮力采样。
- 九种环境预设、昼夜光照、云量、风速、波长、四档质量、像素倍率。
- 使用 Takram 官方 `CloudsEffect` + `AerialPerspectiveEffect`：三维噪声侵蚀、
  天气贴图、多层积云、自阴影、多次散射、大气透视与时间重建。
  主视图直接渲染体积云；同一套参数生成 HDR 立方体贴图供水面反射与环境光使用。
- 水下按真实场景深度积分的透光散射、太阳光束、海底 / 礁石焦散，及植被与鱼群动画。
- 原有 26 个功能入口保留，整理为四类，并修复未创建对象时按名称查找报错、
  重复拾取监听及切换后的资源清理。后处理由同一主循环输出。

海水是独立编写的 WebGL 2 实现；云使用 MIT 开源组件，Three.js 已升级至 r177。
未引入原收费产品的代码。
参考公开技术文档：https://docs.threejswaterpro.com/ 。该站使用三层 FFT 波谱、
程序化大气和动态云层，同时提供 WebGPU 与 WebGL 后端。

当前仍使用平面物体反射、实时近似水下单次散射和主导模态浮力；没有复制原站完整的 SSR
或刚体船舶求解器。云参考切换为用户指定的 Takram Tokyo 示例；海平面视角和
太阳按东京坐标及控制日期计算，海洋的构图不与东京城市示例逐像素相同。

| Medium | 128² | 192² | 官方 medium / 0.85 |

### Takram 体积云

参考示例：https://takram-design-engineering.github.io/three-geospatial/?path=/story/clouds-3d-tiles-renderer-integration--tokyo

文档：https://takram-design-engineering.github.io/three-geospatial/?path=/docs/clouds-readme--docs

- 锁定 `@takram/three-clouds` 0.7.6、`@takram/three-atmosphere` 0.19.1、
  `@takram/three-geospatial` 0.9.1、`postprocessing` 6.39.5。
  使用普通 Three.js API，无 React / R3F 运行时接入。
- 采用官方默认三层云：750–1400 米、1000–2200 米积云及 7500–8000 米高云，
  默认覆盖率 0.37（Tokyo 示例 0.35）。本地 Y 轴朝上坐标转到 Tokyo 的 ECEF 坐标系。
- 天气图、128³ / 32³ 噪声、扰动图、STBN 与大气 EXR 共约 11.1 MiB，
  全部位于 `public/water/takram/`。运行时无需访问 GitHub、Google Maps 或输入 API key。
- 主视图用官方时间升采样；暂停时仍完成 32 帧图像收敛，但天气时间保持不变。
  时间重建在快速转向时仍可能出现短暂噪点或拖影，这是上游算法的限制。
- 反射使用独立的 medium 管线，关闭时间升采样、历史混合和阴影抖动，
  避免不同立方体面串用历史。初始加载和环境参数变化时刷新全部六面，
  之后云移动时每 0.25 模拟秒更新一面；太阳播放时每帧更新一面。
  手动改变日期会立即刷新六面，连续播放使用逐面刷新以控制渲染成本。
- 反射贴图不含太阳圆盘，水面的太阳高光由已有 GGX 计算，避免重复太阳及闪点。
  船舶环境光在参数改变时刷新，天气动画时每 0.5 模拟秒重算 PMREM，复用渲染目标；
  直射光逐帧更新。没有向船舶或岛屿增加移动的云投影。
- 天空以线性 HDR 合成，在最终画面统一色调映射，保留海水、船舶与水下管线。
  所有离屏渲染均恢复原渲染目标、视口和裁剪状态。

起沫集中在高浪峰及覆盖范围，包含 47 米和 80 米波长。固定种子 / 测试时刻的
默认风速 47 米波长强起沫活动面积为 4.52%，80 米为 1.98%；这是模拟场指标，
并不代表整片区域被白沫填满。

额外用生产着色器渲染 8 米近景测试块：即使整个测试块的起沫活动为 1，
表面平均泡沫不透明度仍为 0.0422，71.6% 的像素不透明度低于 0.02，
较亮细丝（不透明度 > 0.3）占 3.89%。同时验证残留泡沫衰减、
无活动区域透明、远处 mip 过滤不会产生白色块。这些是固定条件的回归指标，
不是实际场景屏幕占比或原视频的实测参数。

### 水下透光

“探索水下世界”进入水下视角，仍用 Q / E 下潜与上浮；无需额外开关。

- 空气到水使用 1.333 折射率计算光传播方向，太阳日期 / 时间、云覆盖和日光强度同步
  控制水下照明。水下仰视按约 48.6° 临界角呈现透光窗口和全内反射。
- 水下主画面先渲染到带深度的 HDR 目标，再按相机到物体的距离计算 RGB 消光和单次散射，
  最后统一色调映射。原有水下雾不重复叠加，红光衰减更快，远处逐渐进入深蓝水体。
- 光束使用折射后的光路和已有太阳阴影图，船、岛等水面遮挡物可遮住入射光；场景深度
  截止积分，避免光束直接覆盖到近处船底和礁石上。光束积分范围最多 36 米，四档质量
  分别使用 16 / 28 / 40 / 56 个采样；这是一种实时近似，不是完整的多次散射求解。
- 512² 周期焦散贴图每个海洋模拟帧生成一次，经过 mip 滤波后供光束和场景材质共用。
  焦散是随海洋时钟变化的程序化折射图案，并非从 FFT 波面逐光子求解；按水深和日光
  强度衰减，在材质线性光照阶段作用于海底、礁石、植被和浸水船体，保留物体阴影。
- 全局暂停冻结焦散和光束，太阳动画仍由已有独立天气时钟控制；夜间关闭日光焦散与光束。
  重用原有渲染循环，场景切换释放新增颜色 / 深度目标、焦散贴图和材质。
